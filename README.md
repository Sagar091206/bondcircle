# BondCircle

BondCircle is a Flutter frontend prototype for a trust-first dating app.

## Current frontend scope

1. Login and signup
2. Profile setup
3. Interest circles
4. Discover and match
5. Vibe check
6. Chat
7. Meetup planner
8. Date-friendly venue suggestions
9. Friend-Trust and safety check-in

The first version uses local dummy data and frontend navigation only. Backend APIs, authentication services, maps integration, and real-time chat are outside the current scope.

## Plans tab

The reference screens supplied for the project inspire a separate Plans experience where users can:

- choose a meetup vibe;
- select a date and time;
- choose a public venue;
- add a plan name and description;
- preview and share the completed plan.

The visual direction is a dark purple mobile interface with clear step-by-step forms. The implementation will be original to BondCircle rather than a direct copy of the reference app.

## Reserved future feature

Blind Bond will be discussed and implemented later. It is not part of the current frontend milestone.
